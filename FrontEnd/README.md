# Tremor Ai — Modern Web Frontend

This is the high-performance React 19 + TanStack Router + TailwindCSS frontend for **Tremor Ai**, powered by **Bun** and **Vite**.

---

## 🚀 Quick Start

### 1. Prerequisites
- **Bun 1.4+** (installed at `~/.bun/bin/bun.exe`)

### 2. Install Dependencies
```bash
bun install
```

### 3. Start Development Server
```bash
bun run dev
```
The application will launch at:
- **Local**: `http://localhost:5173/`

### 4. Build for Production
```bash
bun run build
```

---

## 🛠️ Tech Stack
- **Runtime & Package Manager**: Bun
- **Framework**: React 19 + Vite 8
- **Routing & SSR**: TanStack Start / Router
- **Component Library**: Radix UI + TailwindCSS 4
- **State Management**: TanStack React Query 5
- **Charts & Visualization**: Recharts, Lucide Icons
